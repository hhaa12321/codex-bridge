# Codex App Server WebUI v0.3.14

Conversation progress is easier to follow. Context compaction shows an in-progress notice, including when Codex starts it automatically. The floating Goal panel starts as a single line beside the session title and opens only when selected. Running tool groups show elapsed time and finish their running state as soon as the next model step begins.

Session token totals now show reasoning effort for each model. Images produced by tool calls are available in session history. A queued message left behind after its turn has ended can be withdrawn without leaving a stuck card.

The bundled Codex executable lookup follows the current ChatGPT Desktop layout.
