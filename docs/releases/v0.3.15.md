# Codex App Server WebUI v0.3.15

Queued and Steer messages now stay in sync with conversation history during long-running sessions. Messages that have already arrived no longer leave stale cards, and the message stream recovers after temporary connection or authentication failures.

New project directories appear in the session list automatically. The model selector shows the current model and a pending change until the new model takes effect. Replies to clarification prompts are readable in the conversation.

File downloads show progress. On iOS, the file preview offers the system Share sheet so the app remains open. Downloads are transferred in chunks while keeping the existing file access and size limits.
